# AIS Motion — Advanced Editorial Edition

This edition evolves the existing AIS Motion prototype into a more immersive, editorial institutional experience inspired by the rhythm and interaction patterns of premium school/child-development websites such as L'Enfant Roi.

It does **not** copy L'Enfant Roi branding, text, imagery, or proprietary code. AIS content, crest, imagery and identity remain original.

## Added
- Advanced editorial layout layer
- Fixed section index on desktop
- Custom cursor on pointer devices
- Scroll progress and editorial scroll cues
- Enhanced hero composition
- Stronger image framing and hover depth
- Editorial academic journey layout
- Enhanced story-card rhythm
- Refined gallery ribbons
- Better mobile behavior
- Reduced-motion support
- Lazy-loading for non-hero images
